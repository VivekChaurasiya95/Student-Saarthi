Engineering Architecture & Design Principles

Engineered for speed, strict security compliance, and long-term maintainability

Modular Blueprint Architecture

Designed using Flask Application Factory pattern with isolated Blueprints for public portals, authentication gateways, student dashboards, and administrative controls.

SQLAlchemy 2.0 ORM

Declarative mapping with relational foreign key cascades and composite indexes. Supports zero-overhead migrations across SQLite, PostgreSQL, and MySQL.

Enterprise Security Guard

PBKDF2-SHA256 password hashing, HttpOnly SameSite=Lax session cookies, MIME-type and extension file upload sanitization, and parameterized SQL statements.

Dynamic Theme Engine

Zero-latency CSS variable swapping between Executive Light and Deep Obsidian Dark themes, with zero-flash server hydration and instantaneous state synchronization.

28-Suite Pytest Coverage

Automated integration tests validating authentication flows, role-based decorators, multi-parameter scholarship search algorithms, and document uploads.

Automated CI/CD Delivery

Instant packaging and seamless deployment pipelines powered by Antideploy client tooling with live health checks and zero-downtime container spin-up.

Local Development Quickstart

Clone the codebase, run tests, and spin up the development server locally in minutes

bash — student-saarthi
# 1. Clone the official repository
git clone https://github.com/VivekChaurasiya95/Student-Saarthi.git
cd Student-Saarthi

# 2. Setup virtual environment & dependencies
python -m venv .venv
.\.venv\Scripts\Activate.ps1    # Or source .venv/bin/activate on Linux/Mac
pip install -r requirements.txt

# 3. Seed database & run automated tests
python scripts/init_db.py
python scripts/seed_db.py
pytest tests -v

# 4. Launch local server (http://127.0.0.1:5000)
python run.py
