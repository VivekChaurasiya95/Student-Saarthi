System Architecture & Tech Stack

Designed with modularity, security, and developer ergonomics in mind

Application Factory Pattern

Configured using Flask's factory architecture (`create_app`) with cleanly separated Blueprints for public routes, student features, authentication, and administrative controls.

SQLAlchemy 2.0 ORM

Relational entities with foreign key constraints and indexes. Fully portable between local SQLite development and production PostgreSQL or MySQL instances.

Enterprise Security

Session cookies with `HttpOnly` and `SameSite=Lax`, PBKDF2 cryptographic password hashing, parameterized ORM queries, and strict file upload MIME type validation.

Dynamic Theme Engine

Instant CSS design token switching between Light and Dark modes without flash of unstyled theme (FOUT), and zero-flicker server-rendered navigation states.

Automated Pytest Suite

Comprehensive test suite with 26 integration tests covering authentication gateways, role decorators, document uploads, and scholarship filtering algorithms.

Continuous Deployment

Automated archive packaging and zero-downtime deployment pipelines powered by Antideploy client tools.

Local Development Quickstart

Get up and running locally in under 3 minutes

bash / powershell
# 1. Clone the repository git clone https://github.com/VivekChaurasiya95/Student-Saarthi.git cd Student-Saarthi # 2. Create virtual environment & install requirements python -m venv .venv .\.venv\Scripts\Activate.ps1 # Or source .venv/bin/activate on Linux/Mac pip install -r requirements.txt # 3. Initialize database tables & seed verified scholarships python scripts/init_db.py python scripts/seed_db.py # 4. Run automated test suite pytest tests -v # 5. Launch local development server (http://127.0.0.1:5000) python run.py
